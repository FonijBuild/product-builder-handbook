## What belongs here

- Getting started with Fonij
- CLI concepts and commands
- Foundations, blueprints, capabilities, and recipes
- Architecture and progressive-evolution guides
- AI coding-agent workflows
- Practical product-engineering guides

## Documentation principles

- Explain **why** before implementation detail.
- Prefer working, opinionated guidance over exhaustive option lists.
- Keep architecture guidance aligned with the catalog and foundation repositories.
- Keep repository-specific implementation details in that repository's `docs/`.

## Local development

```bash
pnpm install
pnpm dev
```

Run the repository checks before opening a pull request.
